إعدادات وقواعد حماية Firebase المطلوبة (Project: vvbb-3956b)

لكي تعمل عمليات حفظ الصور وقاعدة البيانات بسلاسة وبدون أي قيود، يرجى نسخ القواعد التالية ولصقها في لوحة تحكم Firebase Console لمشروعك:

1. قواعد Firestore Database (قواعد البيانات): 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
2. قواعد Firebase Storage (تخزين الصور المرفوعة): 
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /{allPaths=**} {
      allow read, write: if true;
    }
  }
}
